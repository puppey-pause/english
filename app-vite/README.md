# Английский · React + Vite + FSD

Рефакторинг офлайн-HTML-версии в обычное фронтенд-приложение.

## Запуск

```bash
cd app-vite
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run typecheck
```

## Архитектура — Feature Sliced Design

| Слой | Что внутри |
| --- | --- |
| `app/` | входная точка, стор (Zustand + persist), хеш-роутинг, горячие клавиши, токены и глобальные стили |
| `pages/` | двенадцать разделов приложения, по одному на вкладку |
| `widgets/` | шапка с поиском, навигация по разделам |
| `features/` | поиск, переключатель языка, переключатель темы |
| `entities/` | предметные модели: этап и тема, слово колоды, ошибка, песня |
| `shared/` | UI-кит, данные (113 тем, банк тестов, справочник, сленг, ситуации, песни), i18n, утилиты |

Правило импортов одностороннее: `app → pages → widgets → features → entities → shared`.

## Состояние

Один стор из пяти слайсов (`ui`, `progress`, `deck`, `mistake`, `song`).
В localStorage уходят только данные ученика — прогресс, колода, ошибки, разборы песен;
поисковый запрос и открытая тема не сохраняются. Ключ `en-roadmap-us-v1`, версия схемы 2,
миграция с версии 1 читает старые короткие ключи HTML-версии.

## Стили

CSS Modules рядом с компонентом, все цвета — переменные из `app/styles/tokens.css`.
Шесть тем переключаются атрибутом `data-theme` на `body`.

## Деплой

`.github/workflows/deploy.yml` собирает и публикует `dist/` в GitHub Pages при пуше в `main`.
Подпуть задаётся переменной `VITE_BASE` (сейчас `/english/`).
